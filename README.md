# Access-Control Vulnerability Classification Pipeline

This folder contains a seven-stage machine-learning pipeline for classifying the `Access Control` vulnerability label in smart-contract data. Run the scripts in numerical order because later stages depend on files or decisions produced by earlier stages.

## Project layout

```text
main/
├── code/
│   ├── 1_split_dataset.py
│   ├── 2_remove_multicollinearity.py
│   ├── 3_feature_selection_and_sampling.py
│   ├── 4_compare_model_performance.py
│   ├── 5_bayesian_hyperparameter_tuning.py
│   ├── 6_evaluate_final_model.py
│   └── 7_shap_analysis.py
└── data/
    ├── data.csv
    └── label.csv
```

## Pipeline stages

1. `1_split_dataset.py` merges features and labels, selects numeric features, and creates stratified training and test sets.
2. `2_remove_multicollinearity.py` removes zero-variance, near-constant, and highly correlated features.
3. `3_feature_selection_and_sampling.py` compares RFE, mutual information, and variance-based feature rankings with several sampling methods.
4. `4_compare_model_performance.py` compares the stacking ensemble with a range of individual classifiers.
5. `5_bayesian_hyperparameter_tuning.py` uses Optuna to tune the stacking ensemble for F1 score.
6. `6_evaluate_final_model.py` trains the selected model with the stored best parameters and evaluates it on the held-out test set.
7. `7_shap_analysis.py` calculates SHAP values and saves summary, dependence, interaction, and waterfall plots.

## Requirements

- Python 3.9 or newer
- pandas
- numpy
- scikit-learn
- imbalanced-learn
- xgboost
- lightgbm
- optuna
- shap
- matplotlib

Install the dependencies in your Python environment:

```bash
python -m pip install pandas numpy scikit-learn imbalanced-learn xgboost lightgbm optuna shap matplotlib
```

## Usage

Run all commands from the `code` directory so the relative paths to `../data` resolve correctly:

```bash
cd code
python 1_split_dataset.py
python 2_remove_multicollinearity.py
python 3_feature_selection_and_sampling.py
python 4_compare_model_performance.py
python 5_bayesian_hyperparameter_tuning.py
python 6_evaluate_final_model.py
python 7_shap_analysis.py
```

Stages 3–5 are computationally expensive. The tuning stage runs 200 Optuna trials and allows up to 10 minutes per trial.

## Generated outputs

The scripts create the following files under `../data`:

- `train.csv` and `test.csv`: initial stratified split.
- `train_clean.csv` and `test_clean.csv`: cleaned datasets with aligned features.
- `shap_plots/`: SHAP visualizations generated by the final analysis stage.

## Reproducibility and assumptions

- The random seed is fixed at `42` throughout the pipeline.
- The target column is `Access Control`.
- The final model uses 46 predefined features. These feature names must exist in the cleaned datasets.
- Model evaluation uses a probability threshold of `0.5` and reports ROC AUC, PR AUC, accuracy, precision, recall, and F1 score.
- The source CSV files must contain the join columns `contractAddress` and `contractID`.
